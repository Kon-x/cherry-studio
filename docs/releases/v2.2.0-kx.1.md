# Cherry Studio 2.2.0-kx.1

Windows x64 release of the Kon-x fork, based on official Cherry Studio 2.2.0.

## Changes

- [Desktop] Sync stable upstream 2.2.0 while retaining Chat, Paintings, Translate, Knowledge, Files, Notes, custom assistants, MCP, and tool approvals.
- [Chat] Switch between alternate replies from the message branch counter, reuse generated images as reference inputs, and customize shortcuts for conversations, assistants, and topics.
- [Notifications] View chat completion, approval requests, and announcements in the notification drawer.
- [MCP] Browse updated MCP sources from the existing settings entry.
- [Notes] Save selected conversation text to Notes and reference Notes from the chat input with @.
- [Paintings] Add GPT Image 2.6 Flare and Sunburst options for scene complexity and animated GIF output, and use attached input images in ComfyUI workflows.
- [Export] Export completed translations as full-length PNG images, MCP server configurations as JSON, and multiple assistants as one file.
- [Models] Update the provider and model catalog from the official release snapshot, including LongCat 2.5, Hunyuan 4, and Qwen model controls.

## Fixes

- [Chat] Refresh edited messages immediately, regenerate with the selected model, preserve input height while typing and pasting, and improve history, code rendering, and return-to-bottom scrolling.
- [Providers] Fix Bedrock prompt caching, optional OpenAI Responses tool arguments, parameterless MCP tools, OpenRouter reranking discovery, and Mistral tool-call streams.
- [Notes and Knowledge] Restore matching-line search and formatting behavior, preserve inline and multiline math, and reject invalid knowledge-base URLs before saving.
- [Windows] Hide the main window correctly when closing to the tray and exclude the Snipping Tool from selection retrieval.
- [Privacy] Keep provider API keys out of logs and diagnostic bundles.
- [Fork] Preserve provider deletion and batch deletion, web-grounded selection explanations, direct-provider PDF translation, provider login settings, HTML previews, safe cache inspection, and the fork update feed.

## Upgrade notes

Work/Agents, Mini Apps, Code Mate, Agent skills/tasks, the API Gateway, channel adapters, and remote Agent/browser and computer-control runtimes remain removed. Historical records, user files, external CLI installations, and dormant retired schedules remain preserved. Existing databases migrate forward without deleting historical Agent data.

Setup builds update from this fork; portable builds require a manual update. Cherry Cloud sign-in remains unavailable. Windows executables are not Authenticode-signed.

# Cherry Studio 2.2.0-kx.1

基于 Cherry Studio 官方 2.2.0 的 Kon-x Windows x64 定制版。

## 变更

- [桌面] 同步上游 2.2.0 正式版，保留聊天、绘画、翻译、知识库、文件、笔记、自定义助手、MCP 和工具审批。
- [聊天] 从消息分支计数器切换不同回复，将生成图片用作参考输入，并自定义会话、助手和话题切换快捷键。
- [通知] 在通知抽屉中查看聊天完成、工具审批请求及公告。
- [MCP] 从现有设置入口浏览更新后的 MCP 来源。
- [笔记] 将选中的会话文字保存到笔记，并在聊天输入框中通过 @ 引用笔记。
- [绘画] 为 GPT Image 2.6 Flare 和 Sunburst 增加场景复杂度与动态 GIF 输出选项，并支持 ComfyUI 工作流使用附加图片。
- [导出] 将完整翻译导出为长 PNG 图片，将 MCP 服务器配置导出为 JSON，并将多个助手导出为一个文件。
- [模型] 从官方正式版快照更新服务商和模型目录，包括 LongCat 2.5、Hunyuan 4 及 Qwen 模型控制选项。

## 修复

- [聊天] 编辑消息后立即刷新，重新生成时使用当前选定模型，打字和粘贴时保留输入框高度，并改进历史记录、代码展示及返回底部滚动。
- [服务商] 修复 Bedrock 提示缓存、OpenAI Responses 工具可选参数、无参数 MCP 工具、OpenRouter 重排模型发现及 Mistral 工具调用流。
- [笔记与知识库] 恢复匹配行搜索与格式设置，正确保留行内和多行数学公式，并在保存前拒绝无效的知识库网址。
- [Windows] 关闭到托盘时正确隐藏主窗口，并排除截图工具的选区获取。
- [隐私] 避免在日志和诊断包中记录服务商 API 密钥。
- [定制] 保留服务商删除与批量删除、选区联网解释、直连服务商的 PDF 翻译、登录窗口设置、HTML 预览、安全缓存检查及本 fork 的更新源。

## 升级说明

工作（Agent）、小程序、编码搭档、Agent 技能和定时任务、API 网关、渠道适配器，以及远程 Agent、浏览器和电脑控制运行时继续移除。历史记录、用户文件、外部 CLI 安装及已停用的旧任务继续保留。现有数据库向前迁移，不删除历史 Agent 数据。

安装版从本 fork 更新；便携版需要手动更新。樱桃云登录仍不可用，Windows 程序暂未进行 Authenticode 签名。
