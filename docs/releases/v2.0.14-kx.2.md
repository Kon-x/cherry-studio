# Cherry Studio 2.0.14-kx.2

Windows x64 release of the Kon-x fork, based on official Cherry Studio 2.0.14.

## Changes

- [Desktop] Remove Work/Agents, Mini Apps, Code Mate, DSH, Agent skills/tasks, and the built-in assistant/support Agents. Keep Chat, Paintings, Translate, Knowledge, Files, Notes, custom assistants, MCP, and tool approvals. Windows packages are approximately 22% smaller than kx.1.

## Fixes

- [Data] Opening Clear Cache no longer refreshes the interface or exits the app when large leftover v1 records are present.
- [Providers] Sign-in windows respect the selected language and network settings while preserving authorization callbacks.
- [Updates] Release history recognizes fork revisions and displays them before their upstream base version.

## Upgrade notes

**action required:** Use Chat and custom assistants for new conversations. Retired Agent schedules no longer run, and retired navigation entries are removed. Historical records, user files, and external CLI installations remain on disk.

Setup builds from kx.1 onward update from this fork; portable builds require a manual update.

Cherry Cloud sign-in remains unavailable in this fork. Windows executables are not Authenticode-signed and may show a SmartScreen warning.

# Cherry Studio 2.0.14-kx.2

基于 Cherry Studio 官方 2.0.14 的 Kon-x Windows x64 定制版。

## 变更

- [桌面] 移除工作（Agent）、小程序、编码搭档、DSH、Agent 技能和定时任务，以及内置小助手和反馈智能体。保留聊天、绘画、翻译、知识库、文件、笔记、自定义助手、MCP 和工具审批。Windows 安装包相较 kx.1 缩小约 22%。

## 修复

- [数据] 修复存在大体积 v1 遗留记录时，打开“清除缓存”弹窗导致界面刷新或程序退出的问题。
- [服务商] 登录窗口正确使用所选语言和网络设置，并保留授权回调。
- [更新] 发布历史正确识别 fork 修订版，并将其排在对应的上游基础版本之前。

## 升级说明

**需要操作：** 后续对话请使用聊天和自定义助手。已移除的 Agent 定时任务不再运行，相关导航记录会被清除。历史记录、用户文件及外部 CLI 安装继续保留在磁盘上。

kx.1 及之后的安装版从本 fork 更新；便携版需要手动更新。

本 fork 的樱桃云登录仍不可用。Windows 程序暂未进行 Authenticode 签名，可能触发 SmartScreen。
