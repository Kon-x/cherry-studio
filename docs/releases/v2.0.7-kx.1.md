# Cherry Studio 2.0.7-kx.1

This is the first Kon-x stable fork release, based on official Cherry Studio 2.0.7.

- Tracks official stable upstream tags while preserving upstream Git history.
- Keeps the API Gateway and channel bot adapters removed.
- Supports direct-provider Claude Code and DeepSeek Harness connections; gateway-only routes are rejected.
- Preserves deletable preset providers, batch provider deletion, and web-grounded selection explanations.

The setup build now checks only `Kon-x/cherry-studio` Latest Releases. Install this first fork release manually;
automatic fork updates start with this version. The portable build remains manually updated. Windows binaries are
not Authenticode-signed and may show a SmartScreen warning.

# Cherry Studio 2.0.7-kx.1

这是首个 Kon-x 稳定定制版，基于 Cherry Studio 官方 2.0.7。

- 仅跟随上游正式稳定标签，并保留完整上游 Git 历史。
- 继续移除 API Gateway 和频道机器人适配器。
- Claude Code 与 DeepSeek Harness 仅支持直连服务商；必须经过网关的路由会被明确拒绝。
- 保留预置服务商删除、批量删除服务商和划词解释强制联网能力。

安装版现在仅检查 `Kon-x/cherry-studio` 的 Latest Release。首次定制版需要手动安装，从本版本起才会自动
跟随 fork 更新；便携版仍需手动更新。Windows 二进制暂未进行 Authenticode 签名，可能触发 SmartScreen。
