# Cherry Studio 2.1.3-kx.1

Windows x64 release of the Kon-x fork, based on official Cherry Studio 2.1.3.

## Changes

- [Desktop] Update to upstream 2.1.3 while retaining Chat, Paintings, Translate, Knowledge, Files, Notes, custom assistants, MCP, and tool approvals. Sidebar shortcuts and system diagnostics adopt the updated upstream interface.
- [Models] Update the bundled release catalog, including Claude Opus 5.5, GPT-6 Sol and Luna, Grok 4.7, and MiMo V2.6 models.
- [Documents] Support self-hosted MinerU 4 and system OCR on Windows.

## Fixes

- [Chat] Improve reasoning display, token usage, scroll following, Responses continuations, and migrated image paths. Render error details safely as text.
- [Network] Improve proxy handling for local addresses, model synchronization, and connection diagnostics.
- [Windows] Handle blocked native shutdown addons and transient file-watcher failures more reliably.
- [Fork] Preserve provider deletion and batch deletion, web-grounded explanations, direct-provider PDF translation, provider login settings, HTML previews, and safe cache inspection.

## Upgrade notes

Work/Agents, Mini Apps, Code Mate, Agent skills/tasks, the API Gateway, channel adapters, and remote Agent/browser runtimes remain removed. Historical records, user files, external CLI installations, and dormant retired schedules remain preserved. Existing databases migrate forward without deleting historical Agent data.

Setup builds update from this fork; portable builds require a manual update. Cherry Cloud sign-in remains unavailable. Windows executables are not Authenticode-signed.

# Cherry Studio 2.1.3-kx.1

基于 Cherry Studio 官方 2.1.3 的 Kon-x Windows x64 定制版。

## 变更

- [桌面] 同步上游 2.1.3，保留聊天、绘画、翻译、知识库、文件、笔记、自定义助手、MCP 和工具审批。侧栏快捷方式与系统诊断采用上游新版界面。
- [模型] 更新内置正式版模型目录，包括 Claude Opus 5.5、GPT-6 Sol 和 Luna、Grok 4.7，以及 MiMo V2.6 系列。
- [文档] 支持自托管 MinerU 4 和 Windows 系统 OCR。

## 修复

- [聊天] 改进思考内容展示、用量统计、滚动跟随、Responses 续接和迁移图片路径；错误详情以纯文本安全展示。
- [网络] 改进本地地址代理处理、模型同步和连接诊断。
- [Windows] 更稳妥地处理原生关机组件被系统阻止以及文件监视器临时故障。
- [定制] 保留服务商删除与批量删除、联网解释、直连服务商的 PDF 翻译、登录窗口设置、HTML 预览及安全缓存检查。

## 升级说明

工作（Agent）、小程序、编码搭档、Agent 技能和定时任务、API 网关、渠道适配器，以及远程 Agent 和浏览器运行时继续移除。历史记录、用户文件、外部 CLI 安装及已停用的旧任务继续保留。现有数据库向前迁移，不删除历史 Agent 数据。

安装版从本 fork 更新；便携版需要手动更新。樱桃云登录仍不可用，Windows 程序暂未进行 Authenticode 签名。
