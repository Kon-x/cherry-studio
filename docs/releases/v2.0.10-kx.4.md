# Cherry Studio v2.0.10-kx.4

## 🐛 Bug Fixes

### Network Stability

- **AI 请求自动重试**：当系统网络路径变化（加速器启动、网卡切换、代理变更）时，AI 请求现在会自动重试一次，无需手动重启应用或切换代理设置
  - 覆盖的错误类型：`net::ERR_FAILED`、`net::ERR_NETWORK_CHANGED`、`net::ERR_PROXY_CONNECTION_FAILED`、DNS 解析失败、连接重置/拒绝
  - 重试间隔 1 秒，仅针对失败的单个请求，不影响其他正在进行的对话流
  - 非瞬态错误（证书验证失败、超时等）仍立即抛出，保持原有行为

## 🐛 Bug Fixes

### Network Stability

- **Automatic AI request retry**: When the OS network path changes (VPN/proxy startup, adapter change), AI requests now automatically retry once without requiring manual app restart or proxy setting toggle
  - Covered error types: `net::ERR_FAILED`, `net::ERR_NETWORK_CHANGED`, `net::ERR_PROXY_CONNECTION_FAILED`, DNS resolution failures, connection reset/refused
  - 1-second retry delay, applies only to the failed request without disrupting other ongoing conversation streams
  - Non-transient errors (cert validation failures, timeouts) still throw immediately, preserving original behavior
