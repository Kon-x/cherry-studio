# Cherry Studio 2.1.10-kx.1

Windows x64 release of the Kon-x fork, based on official Cherry Studio 2.1.10.

## Changes

- [Desktop] Sync stable upstream releases 2.1.4 through 2.1.10 while retaining Chat, Paintings, Translate, Knowledge, Files, Notes, custom assistants, MCP, and tool approvals.
- [Voice] Add dictation and streaming speech playback, including the fix for long local dictation losing its second half.
- [Files] Update shared previews and editing, with file tabs, preview settings, and preserved reading position when refreshing.
- [Updates] Show skipped stable release notes in a collapsible timeline and preserve this fork's release history and update feed.
- [Network] Add proxy connection testing and update the bundled provider/model catalog from the official release snapshot.

## Fixes

- [Chat] Improve streaming replay, code-block scrolling, reasoning display, conversation tab titles, and editing queued follow-up messages.
- [Knowledge] Improve indexing and file-conversion progress, restart recovery, ordering, and large-library deletion.
- [Fork] Preserve provider deletion and batch deletion, web-grounded selection explanations, direct-provider PDF translation, provider login settings, HTML previews, and safe cache inspection.

## Upgrade notes

Work/Agents, Mini Apps, Code Mate, Agent skills/tasks, the API Gateway, channel adapters, and remote Agent/browser and computer-control runtimes remain removed. Historical records, user files, external CLI installations, and dormant retired schedules remain preserved. Existing databases migrate forward without deleting historical Agent data.

Setup builds update from this fork; portable builds require a manual update. Cherry Cloud sign-in remains unavailable. Windows executables are not Authenticode-signed.

# Cherry Studio 2.1.10-kx.1

基于 Cherry Studio 官方 2.1.10 的 Kon-x Windows x64 定制版。

## 变更

- [桌面] 同步上游 2.1.4 至 2.1.10 正式版本，保留聊天、绘画、翻译、知识库、文件、笔记、自定义助手、MCP 和工具审批。
- [语音] 加入听写和流式语音播放，并修复本地听写较长语音时丢失后半段的问题。
- [文件] 更新共享文件预览和编辑，支持文件标签页、预览设置，以及刷新时保留阅读位置。
- [更新] 通过可折叠时间轴展示跨版本更新说明，保留本 fork 的发布历史和更新源。
- [网络] 加入代理连接测试，并从官方正式版快照更新内置服务商和模型目录。

## 修复

- [聊天] 改进流式回放、代码块滚动、思考内容展示、会话标签标题及待发送后续消息的编辑。
- [知识库] 改进索引和文件转换进度、重启恢复、排序，以及大型知识库的删除效率。
- [定制] 保留服务商删除与批量删除、选区联网解释、直连服务商的 PDF 翻译、登录窗口设置、HTML 预览及安全缓存检查。

## 升级说明

工作（Agent）、小程序、编码搭档、Agent 技能和定时任务、API 网关、渠道适配器，以及远程 Agent、浏览器和电脑控制运行时继续移除。历史记录、用户文件、外部 CLI 安装及已停用的旧任务继续保留。现有数据库向前迁移，不删除历史 Agent 数据。

安装版从本 fork 更新；便携版需要手动更新。樱桃云登录仍不可用，Windows 程序暂未进行 Authenticode 签名。
