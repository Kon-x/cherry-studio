# Cherry Studio 2.0.10-kx.3

This Kon-x stable fork release tracks official Cherry Studio 2.0.10.

## Fixed

- [Network] The app no longer loses connectivity until restarted when the network path is rebuilt underneath it —
  a VPN or game accelerator raising or dropping its virtual adapter, a Wi-Fi/Ethernet switch, or waking from sleep.
  Chromium keeps sockets and DNS entries that such a change silently invalidates, and re-applying the same proxy
  configuration did not replace them. The proxy is now force-applied on an interface change and on resume, dropping
  stale connections, the DNS cache, and the cached proxy resolution. Requests in flight at that moment are cancelled
  and need to be retried. A proxy client that only rewrites the routing table, adding no adapter, is still not
  detected.

## Fork baseline

- Tracks official stable upstream tags while preserving upstream Git history.
- Keeps the API Gateway and channel bot adapters removed.
- Supports direct-provider Claude Code and DeepSeek Harness connections; gateway-only routes are rejected.
- Preserves deletable preset providers, batch provider deletion, and web-grounded selection explanations.
- PDF (BabelDOC) translation talks to the selected provider's own OpenAI-compatible endpoint instead of the removed gateway.

Setup builds update only from `Kon-x/cherry-studio` Latest Releases. The portable build remains manually updated.
Windows binaries are not Authenticode-signed and may show a SmartScreen warning.

# Cherry Studio 2.0.10-kx.3

本 Kon-x 稳定定制版跟随 Cherry Studio 官方 2.0.10。

## 修复

- [网络] 底层网络路径被重建后不再需要重启才能恢复联网——包括 VPN 或游戏加速器启用/关闭虚拟网卡、Wi-Fi 与有线网络
  切换、以及睡眠唤醒。这类变化会让 Chromium 持有的连接和 DNS 记录静默失效，而重新下发同一份代理配置并不会替换它们。
  现在网卡变化和系统唤醒会强制重新应用代理，同时丢弃陈旧连接、DNS 缓存和已缓存的代理解析结果。此刻正在进行的请求会
  被中断，需要重试。仅改写路由表、不新增虚拟网卡的代理客户端仍无法被检测到。

## 定制版基线

- 仅跟随上游正式稳定标签，并保留完整上游 Git 历史。
- 继续移除 API Gateway 和频道机器人适配器。
- Claude Code 与 DeepSeek Harness 仅支持直连服务商；必须经过网关的路由会被明确拒绝。
- 保留预置服务商删除、批量删除服务商和划词解释强制联网能力。
- PDF（BabelDOC）翻译改为直连所选服务商自身的 OpenAI 兼容端点，不再依赖已移除的网关。

安装版仅从 `Kon-x/cherry-studio` 的 Latest Release 更新；便携版仍需手动更新。Windows 二进制暂未进行
Authenticode 签名，可能触发 SmartScreen。
