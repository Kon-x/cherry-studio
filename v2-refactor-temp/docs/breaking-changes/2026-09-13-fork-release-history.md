## What changed

Release history includes the fork's published `kx.n` revisions alongside upstream stable versions. Fork revisions appear before their corresponding upstream base, with the latest revision first.

## Why this matters to the user

Online and bundled release history show the changes shipped by the fork, including feature removals and fixes, instead of showing only upstream release notes.

## What the user should do

Nothing — automatic.
